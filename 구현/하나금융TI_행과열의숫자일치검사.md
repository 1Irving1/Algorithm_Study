# [문제] 행과 열의 숫자 일치 검사

## 문제 설명

크기가 R1 x C1인 2차원 배열 arr1과 크기가 R2 x C2인 2차원 배열 arr2가 주어집니다.
주어진 두 배열을 비교하여 크기가 R1 x C1인 결과 2차원 배열 result를 생성해야 합니다.

arr1의 모든 위치 (i, j) (0 <= i < R1, 0 <= j < C1)에 대해 아래 조건의 순서대로 result[i][j]의 값을 결정합니다.

1. arr2의 i번째 행에 arr1[i][j]와 같은 숫자가 존재한다면, result[i][j]에 해당 숫자를 넣습니다. (단, i가 arr2의 행 개수 R2 이상인 경우 i번째 행은 존재하지 않는 것으로 간주합니다.)
2. 1번 조건에 해당하지 않고, arr2의 j번째 열에 arr1[i][j]와 같은 숫자가 존재한다면, result[i][j]에 해당 숫자를 넣습니다. (단, j가 arr2의 열 개수 C2 이상인 경우 j번째 열은 존재하지 않는 것으로 간주합니다.)
3. 위 1번과 2번 조건에 모두 해당하지 않는다면, result[i][j]에 0을 넣습니다.

arr1과 arr2가 입력으로 주어질 때, 완성된 result 배열을 반환하는 코드를 작성해 주세요.

---

## 제약 사항

- 시간 제한: 1.0초
- 메모리 제한: 512MB
- R1, C1 (arr1의 행과 열 크기): 1 이상 1,000 이하의 자연수
- R2, C2 (arr2의 행과 열 크기): 1 이상 1,000 이하의 자연수
- 배열 내 원소의 값: -1,000,000,000 이상 1,000,000,000 이하의 정수

---

## 입출력 예시

### 예시 1

arr1:
1 2 3
4 5 6

arr2:
2 9 8
7 5 4

result:
0 2 0
4 5 0

#### 설명

- arr1[0][0] = 1: arr2의 0행 [2, 9, 8]에 1 없음, 0열 [2, 7]에 1 없음 -> 0
- arr1[0][1] = 2: arr2의 0행 [2, 9, 8]에 2 있음 -> 2
- arr1[0][2] = 3: arr2의 0행 [2, 9, 8]에 3 없음, 2열 [8, 4]에 3 없음 -> 0
- arr1[1][0] = 4: arr2의 1행 [7, 5, 4]에 4 있음 -> 4
- arr1[1][1] = 5: arr2의 1행 [7, 5, 4]에 5 있음 -> 5
- arr1[1][2] = 6: arr2의 1행 [7, 5, 4]에 6 없음, 2열 [8, 4]에 6 없음 -> 0
